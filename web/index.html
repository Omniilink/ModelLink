Help & Tutorial

Welcome to Omniilink

Omniilink is a multi-provider AI load balancer. It routes your prompts to the best available AI model automatically.

Getting Started

  1. Add API Keys — Go to Settings and add at least one provider key (Groq is free and fast)
  2. Start Chatting — Type a message and press Enter. Omniilink auto-routes to the best model.
  3. Choose a Model — Click the model button to pick a specific provider, or leave it on "omnilink" for auto-routing.

Smart Routing

When set to "omnilink", the system classifies your message as simple, medium, or complex, then picks the best model for the task.

Coding Mode

Click the code icon in the sidebar to switch to Coding Mode. This provides a file tree, project management, and a terminal panel.

Prompts Library

Save and reuse prompt templates. Organize by category: Coding, Writing, Analysis, or Custom.

Keyboard Shortcuts

  • Ctrl+Enter — Send message
  • Ctrl+N — New chat
  • Ctrl+/ — Open help
  • Escape — Close menus

Free API Keys

You can get free API keys from:

  • Groq — console.groq.com (free, fast inference)
  • Gemini — aistudio.google.com (free tier)
  • OpenRouter — openrouter.ai (free models available)

Account

Create an account at signup.omniilink.workers.dev to save your API keys and access Omniilink from any device.
