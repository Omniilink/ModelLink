Help & Tutorial

Welcome to Omniilink

Omniilink is a multi-provider AI load balancer. It routes your prompts to the best available AI model automatically.

Getting Started

  1. Add API Keys — Go to Providers and add at least one key (Groq is free and fast — each provider card has a setup guide)
  2. Start Chatting — Type a message and press Enter. Omniilink auto-routes to the best model.
  3. Choose a Model — Click the model button to pick a specific provider, or leave it on "omniilink" for auto-routing.

Smart Routing

When set to "omniilink", the system classifies your message as simple, medium, or complex, then picks the best model for the task.

Reasoning controls: Effort & Think

The two dropdowns next to the model button control how hard the AI thinks before answering. They apply per message, are remembered between visits, and are mirrored in Coding mode.

  • Effort — how much reasoning work to spend: minimum answers instantly with almost no deliberation, low/medium suit everyday questions, high and above dig into hard problems step by step. Higher effort is slower and uses more tokens.
  • Think — the thinking budget: how many intermediate reasoning tokens the model may use. minimum forces a direct answer, larger budgets let it work through complex chains. Where a provider supports only one knob, thinking wins.
  • Auto — lets the router pick a sensible level for the task. Start here; raise a level only when answers feel shallow, lower one when they feel slow.

Rule of thumb: easy chat stays on auto/low, code and math go medium/high, and only genuinely hard debugging earns xhigh or max.

Images in chat

The picture button next to the message box attaches up to 4 images (auto-compressed). They need a vision-capable model: pick Gemini, GPT-4o, or Claude — or leave omniilink on auto and it routes to one for you. Other models will tell you they cannot see images.

Coding Mode

Click the code icon in the sidebar to switch to Coding Mode. This provides a file tree, project management, and a terminal panel.

Prompts Library

Save and reuse prompt templates. Organize by category: Coding, Writing, Analysis, or Custom.

You can get free API keys from:

  • Groq — console.groq.com (free, fast inference)
  • Gemini — aistudio.google.com (free tier)
  • OpenRouter — openrouter.ai (free models available)

Account

Create an account right here with the Sign In button to save your API keys and access Omniilink from any device.

Admin Panel

Admins get an Admin button in the left sidebar. It opens https://omniilink.dpdns.org/admin — user management, usage stats, server logs, a full server terminal, Docker controls, and one-click server updates.

Provider setup guides

Get a key from your provider, then go to Providers (sidebar) → + Add and paste it in.

Google Gemini

  1. Open aistudio.google.com and sign in
  2. Click Create API key and copy it (free tier included)
  3. Paste it into Providers → Add → Google Gemini, then pick any Gemini model
  4. Keys start with AIza — keep the tab open until it works
  5. Free tier included: generous daily request limits that reset overnight
  6. If calls fail with API key not valid, open the key's settings and set API restrictions to None

OpenAI (ChatGPT)

  1. Open platform.openai.com and sign in
  2. Copy the key immediately — it starts with sk-proj- and is never shown again
  3. Paste it into Providers → Add → OpenAI
  4. New accounts must add a payment method and buy credit (from $5) before API calls work — without it you get insufficient_quota
  5. If a key leaks, revoke it on the same page and make a new one

Anthropic (Claude)

  1. Open console.anthropic.com and sign in
  2. Click Create Key, name it, and copy it — it starts with sk-ant- and is shown once
  3. Paste it into Providers → Add → Anthropic
  4. There is no free tier: add credit under Billing or calls fail — Sonnet is the sensible default, Haiku is cheapest
  5. authentication_error means a stray space got pasted or the key was revoked — re-copy it cleanly

OpenRouter

  1. Open openrouter.ai and sign in
  2. Click Create API Key, name it, and copy it — it starts with sk-or-v1-
  3. Paste it into Providers → Add → OpenRouter
  4. One key reaches hundreds of models; names ending in :free cost nothing — paid ones need credit under Credits
  5. Rate limits are per model: if a free model 429s, wait a minute or pick another

Groq

  1. Open console.groq.com and sign in
  2. Click Create API Key, give it a name, and submit
  3. Copy the key — it starts with gsk_ and is shown once — then paste it into Providers → Add → Groq
  4. Free tier is generous and very fast; limits are per-minute per model, so a 429 means slow down, not pay up
  5. Start with llama-3.1-8b-instant for drafts — the fastest cheap option they have

Mistral

  1. Open console.mistral.ai and sign in
  2. Click Create new key and copy it
  3. Paste it into Providers → Add → Mistral
  4. New accounts often include trial credit; heavier models need billing enabled under Billing
  5. mistral-small-latest is the sweet spot for everyday chat and code

Together AI

  1. Open api.together.ai and sign in
  2. Click Add API key and copy it
  3. Paste it into Providers → Add → Together AI
  4. New accounts get free trial credits — good for open models like Llama 3.3 70B
  5. Model names include the org prefix (e.g. meta-llama/Llama-3.3-70B-Instruct-Turbo) — copy them exactly, case matters

DeepSeek

  1. Open platform.deepseek.com and sign in
  2. Click Create API key, name it, and copy it — it starts with sk-
  3. Paste it into Providers → Add → DeepSeek
  4. Prepaid balance required (very cheap per token) — top up or calls fail
  5. Use deepseek-chat for everyday work, deepseek-reasoner when you want it to think longer

Cohere

  1. Open dashboard.cohere.com and sign in
  2. Copy the trial key, or click Create API key for a production one
  3. Paste it into Providers → Add → Cohere
  4. Trial keys are rate-limited — fine for testing, upgrade to a plan for real use
  5. command-r-plus is the capable one, command-r the lighter one

OpenCode Zen

  1. Open opencode.ai and sign in
  2. Copy your Zen API key
  3. Paste it into Providers → Add → OpenCode Zen
  4. Usage draws from your OpenCode balance/plan — check their pricing page for current rates
  5. If models list as unavailable, the key usually expired: generate a fresh one

Ollama (local)

Run models on the server machine itself — no API key, no cloud. The server connects to Ollama, auto-detects your installed models, and lists each one in the model menu.

  1. Install Ollama on the server machine (ollama.com/download) and make sure ollama serve is running
  2. Pull at least one model there, e.g. ollama pull llama3.1:8b (ollama list shows what is installed)
  3. Point the server at it below, press Test until it reports connected, then Save — installed models appear in the model menu under Ollama (local) automatically
  4. Gotchas: the URL is resolved by the server, not your browser — localhost means the server machine. From another device use the server's LAN IP, e.g. http://192.168.1.50:11434

Using a paired computer instead? Pair any computer under Admin > Agents and press Test Ollama on its setup page — its local Ollama models are shared with your account and appear in the model menu as Ollama · name. They work from anywhere over the internet, only you can use them, and they show greyed out with an offline badge when that computer is not running.

Custom (OpenAI-compatible)

  1. Pick any OpenAI-compatible endpoint and note its base URL — it must end in /v1: LM Studio is http://localhost:1234/v1, vLLM is http://your-host:8000/v1. (Ollama needs no Custom entry — use Ollama (local) above instead.)
  2. Note the exact model name (ollama list shows yours — spelling and tags must match exactly)
  3. Go to Providers → Add → Custom and fill in a short lowercase name, the API link, a key (any string works for local servers with no auth), and the model
  4. Pick custom/your-name from the model menu
  5. Test it from a terminal first: curl $BASE/chat/completions -H "Authorization: Bearer $KEY" -d '{"model":"...","messages":[{"role":"user","content":"hi"}]}' — if curl fails, Omniilink fails the same way
  6. Gotchas: localhost means the server machine, not your phone — use the machine's LAN IP for other devices; self-signed HTTPS endpoints are rejected, use plain HTTP locally or a valid cert
