02 — Product

One workspace, four jobs.

Each part does one thing well, and your work carries over between them.

Smart routing

Leave the model on omnilink and every prompt is classified and sent to the cheapest capable model you configured — or pick any model yourself, per message.

Agentic coding

A file tree, terminal, git, live preview, and version history, with a loop that writes, runs, and verifies — and asks before anything executes.

Media tools

YouTube downloads that land straight in your browser at the quality and codec you pick, plus a file converter. No server-side waiting room.

OpenAI-compatible API

Point Cursor, Cline, Continue, or plain curl at /v1 and use your configured providers from the tools you already live in.

05 — FAQ

Asked often.

The short answers. Longer ones live in the in-app Help page.

Do I need my own API keys?

Yes. Omniilink routes your requests but the inference bill stays between you and the provider. Groq and Gemini both have free tiers that cover a lot, and setup guides for all ten providers are built into the app.

Is my key safe?

Keys are stored on your own Omniilink server, sent only to the provider you chose, and shown masked everywhere in the UI. Nobody else's requests can touch them.

What does Omniilink itself cost?

Nothing while in beta. A paid tier is planned for later; everything free today stays free.

Can I use local models?

Yes. Ollama on your machine is auto-detected, and any OpenAI-compatible endpoint — vLLM, LM Studio, a VPS — can be added as a custom provider with its base URL.

Do I install anything?

No. It runs in the browser. The optional server piece is a single self-hosted install if you ever want your own instance.
